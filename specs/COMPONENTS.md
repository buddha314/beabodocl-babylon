## Babylon.js Scripts

### Box Script (`src/scripts/box.ts`)

**Purpose:** Rotation animation for box mesh

**Type:** IScript implementation (Babylon.js Editor)

**Class:**
```typescript
export default class SceneComponent implements IScript {
  @visibleAsNumber("Speed", { min: 0, max: 0.1 })
  private _speed: number = 0.04;

  public constructor(public mesh: Mesh) {}

  public onStart(): void {}

  public onUpdate(): void {
    this.mesh.rotate(
      Vector3.UpReadOnly,
      this._speed * this.mesh.getScene().getAnimationRatio()
    );
  }
}
```

**Decorator:**
- `@visibleAsNumber` - Exposes property in Babylon.js Editor
- Configurable via editor UI
- Min/max constraints

**Animation:**
- Runs every frame (onUpdate)
- Rotates around Y-axis (up)
- Speed adjusted for frame rate
- Smooth at any FPS

**Editor Integration:**
- Automatically attached to meshes in editor
- Can be assigned via scripts map
- Properties editable in inspector

**Scripts Map:**
```typescript
// src/scripts.ts
export const scriptsMap = {
  "scripts/box.ts": scripts_box
};
```

## Component Best Practices

### Client Components
- Use `"use client"` for interactivity
- Required for hooks (useState, useEffect)
- Required for Babylon.js (browser-only)

### Server Components
- Default in App Router
- Better performance
- Can fetch data directly
- Cannot use browser APIs

### Refs for 3D
- Use refs for canvas elements
- Don't store engine/scene in state
- Cleanup in useEffect return

### Error Boundaries
- Not currently implemented
- Recommended for production
- Wrap 3D scene separately

### Accessibility
- Canvas not accessible by default
- Add ARIA labels for controls
- Provide keyboard alternatives
- Announce state changes
